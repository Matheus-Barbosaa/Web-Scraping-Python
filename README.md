# Web Scraping com Python

## Sobre o projeto

Este projeto tem como objetivo praticar Web Scraping com Python para coletar informações de um catálogo de livros disponível na web.

A proposta é extrair os dados, organizar as informações coletadas e exportar os resultados para um arquivo CSV, facilitando análises posteriores.

## Objetivos

- Praticar a coleta de dados de páginas web.
- Fazer requisições HTTP com `Requests`.
- Extrair informações HTML com `BeautifulSoup`.
- Organizar e tratar os dados com `Pandas`.
- Exportar os resultados para CSV.
- Praticar a organização de um projeto Python.

## Tecnologias utilizadas

- Python
- Requests
- BeautifulSoup
- Pandas
- CSV
- Git e GitHub

## Dados coletados

O projeto utiliza o catálogo de demonstração [Books to Scrape](https://books.toscrape.com/), que disponibiliza informações de livros para exercícios de Web Scraping.

Os dados previstos para coleta incluem:

- Título do livro
- Preço
- Avaliação
- Link do livro

## Como executar

1. Clone este repositório.
2. Crie e ative um ambiente virtual Python.
3. Instale as dependências listadas em `requirements.txt`.
4. Execute o script de coleta.
5. Confira o arquivo CSV gerado.

As instruções detalhadas serão atualizadas conforme a estrutura final do projeto for organizada e testada.
